# Dead-Chicken-Detection & Behavioral Analysis

YOLOv8 기반 객체 탐지와 움직임 분석을 활용한 양계장 폐사 의심 개체 모니터링 시스템

## 프로젝트 개요

양계장 영상에서 닭을 탐지하고, 개체별 위치 변화와 탐지 이력을 분석하여 **장시간 움직임이 없는 폐사 의심 개체를 표시하는 시스템**입니다.

저화질 영상과 개체 간 가림으로 탐지가 끊기는 문제를 고려하여, 시간에 따른 움직임과 바운딩 박스의 위치 연속성을 판단에 활용했습니다.

> 시스템이 표시하는 ‘폐사 의심’은 실제 폐사를 확정하는 결과가 아니며, 관리자의 현장 확인이 필요합니다.

## 개발 배경

프로젝트를 시작하면서 가장 어려웠던 점은 **폐사한 닭을 어떤 기준으로 판단할 것인가**였습니다.

- 저화질의 넓은 촬영 화면에서는 개체가 작게 보여 탐지가 불안정했습니다.
- 잠자는 닭과 폐사한 닭은 외형과 움직임이 유사하여 구분하기 어려웠습니다.
- 다른 닭이 대상 개체를 가리면 바운딩 박스가 사라져 관찰 이력이 끊겼습니다.

이러한 문제를 해결하기 위해 **탐지 지속 시간, 객체의 이동 거리, 탐지 재연결**을 활용했습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 객체 탐지 및 추적 | YOLOv8을 활용하여 닭을 탐지하고, 개체별 ID와 위치 이력을 관리합니다. |
| 그리드 기반 처리 | 고해상도 프레임을 3×3 영역으로 분할하여 탐지합니다. |
| 움직임 기반 상태 분류 | 객체 중심점의 이동 거리를 바탕으로 Active·Stationary·Dead 상태를 구분합니다. |
| IoU 기반 탐지 재연결 | 일시적으로 탐지가 끊긴 객체를 이전 바운딩 박스와 비교하여 연결을 시도합니다. |
| 상태 복구 | 움직임이 다시 감지되면 Active 상태로 복구합니다. |
| 결과 시각화 | 개체별 상태를 바운딩 박스의 색상으로 표시합니다. |
| 데이터 로깅 | 프레임별 개체 상태를 `chicken_status_log.csv`에 저장합니다. |

## 개발 과정과 문제 해결

### 1. 탐지 지속 시간을 활용한 판단

#### 문제

단일 프레임의 탐지 결과만으로는 휴식 중인 닭과 폐사한 닭을 구분하기 어려웠습니다. 저화질 영상에서는 탐지 결과가 일시적으로 흔들리는 문제도 있었습니다.

#### 적용한 방법

초기에는 폐사 의심 대상으로 탐지된 바운딩 박스가 **5초 이상 연속으로 유지되는지** 확인하고, 조건을 충족하면 빨간색으로 표시하도록 구성했습니다.

한 번의 탐지 결과에 즉시 반응하는 대신, 일정 시간 동안 유지되는 탐지 결과를 판단에 반영했습니다.

### 2. 가림으로 끊긴 탐지 이력 연결

#### 문제

다른 닭이 대상 개체 위로 지나가면 바운딩 박스가 사라졌습니다.

이때 연속 탐지 시간이 초기화되어, 같은 위치에 있는 개체도 5초 조건을 충족하기 어려웠습니다.

#### 적용한 방법

탐지가 끊기기 직전의 바운딩 박스 위치를 저장하고, **1~3초 이내에 유사한 위치에서 다시 탐지되면 IoU를 비교**하여 이전 객체와 연결하도록 구성했습니다.

IoU(Intersection over Union)는 두 바운딩 박스가 겹치는 정도를 나타냅니다.

$$
IoU = \frac{\text{두 바운딩 박스의 교집합 면적}}{\text{두 바운딩 박스의 합집합 면적}}
$$

짧은 가림 이후 다시 탐지된 객체를 이전 객체와 연결하여, 관찰 이력을 이어갈 수 있도록 했습니다.

다만 가까운 위치에 다른 개체가 들어오면 잘못 연결될 가능성이 있으므로, IoU만으로 동일 개체임을 보장할 수는 없습니다.

## 움직임 분석 방법

탐지의 연속성 확인과 별도로, 추적 중인 객체의 **중심점 이동 거리**를 계산하여 활동 상태를 분류합니다.

연속된 프레임 사이의 유클리드 거리는 다음과 같습니다.

$$
d_t = \sqrt{(x_t-x_{t-1})^2 + (y_t-y_{t-1})^2}
$$

- $(x_t, y_t)$: 현재 프레임의 객체 중심점
- $(x_{t-1}, y_{t-1})$: 이전 프레임의 객체 중심점
- $\epsilon$: 움직임 여부를 구분하는 거리 임계값

이동 거리 $d_t$가 임계값 $\epsilon$보다 작은 상태가 지속되면 정지 프레임을 누적합니다.

### 상태 분류 기준

| 상태 | 분류 기준 | 표시 색상 |
|---|---|---|
| Active | 움직임이 감지된 상태 | 초록색 |
| Stationary | 움직임이 없는 상태가 150프레임 이상 지속 | 노란색 |
| Dead | 움직임이 없는 상태가 450프레임 이상 지속하여 폐사가 의심되는 상태 | 빨간색 |

Stationary 또는 Dead 상태에서도 움직임이 다시 감지되면 **Active로 복구**합니다.

> `Dead`는 시스템 내부의 상태명이며, 실제 폐사를 확정하는 의미는 아닙니다.
>
> 초기의 ‘5초 연속 탐지’는 탐지 유지 여부를 확인하는 조건이며, ‘150·450프레임’은 움직임이 없는 기간을 평가하는 조건입니다. 프레임 수에 대응하는 실제 시간은 영상의 FPS와 프레임 처리 방식에 따라 달라집니다.

## 한계점 및 향후 과제

### 휴식과 폐사의 구분

장시간 움직이지 않는 휴식 개체도 폐사 의심으로 분류될 수 있습니다.

향후 Optical Flow를 활용하여 미세한 움직임을 분석하고, 호흡 움직임을 구분에 활용할 수 있는지 검토할 예정입니다.

### 가림 상황에서의 개체 식별

IoU 기반 연결은 위치 중첩을 활용하므로, 개체가 밀집하거나 서로 자리를 바꾸면 잘못 연결될 수 있습니다.

향후 Re-identification(Re-ID)을 활용하여 개체 식별을 보완할 계획입니다.

### 고정 임계값의 한계

시간대와 일주기 리듬에 따라 닭의 활동량이 달라질 수 있으나, 고정 임계값은 이러한 차이를 충분히 반영하지 못합니다.

향후 시간대별 활동 패턴을 고려한 동적 임계값 적용을 검토할 예정입니다.

탐지 정확도와 개선 효과를 확인하려면 폐사 의심 탐지의 정밀도·재현율, 오탐률, 가림 이후 동일 개체 연결 성공률 등을 측정해야 합니다.
